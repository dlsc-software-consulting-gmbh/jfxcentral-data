BellSoft offers multiple solutions for various tasks related to development, deployment, 
and execution of Java applications. Their expertise enables them to create 
an optimal environment for developing and running Java applications efficiently 
and with a minimal environmental impact.

The company provides supported JDK builds and a GraalVM CE-based distribution 
bundled with OpenJFX, enabling the developers to write desktop applications 
without adding the additional dependencies and turn them into native executables 
that don’t require a JVM to run.
