## Miscellaneous

* [Tip by **Matt Coley**](https://bsky.app/profile/mattcoley.bsky.social/post/3m3wok2nync2m): "_If you're using the JavaFX 'Flowless' library for virtualized controls and are observing sluggish performance, do not add stylesheets to the Virtualized Node. Add them to the Scene. I observed an immediate 10x performance boost by doing this._" A video demo is [available here](https://www.youtube.com/watch?v=l4PcbsDa-zU).
