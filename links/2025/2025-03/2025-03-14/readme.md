## Core

* [JavaFX performance tip by **Johan Vos**](https://mastodon.social/@johanvos/114097968879188574): "_In a flow where data is changed, avoid using `Platform.runLater()` until as close as possible to code that does a UI update. The FX App Thread is single-threaded and also needs to render the SG. Do not use it for things that can run on other threads._"
