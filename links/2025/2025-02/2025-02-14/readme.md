## Core

* Early access builds of JavaFX that implement the new macOS Metal graphics rendering pipeline are now available. [More info and link on Inside Java](https://inside.java/2025/02/11/quality-heads-up/): "_These EA builds are provided as a convenience, so users don’t have to build from the 'metal' branch of the openjdk/jfx-sandbox repository. The goal of these early access builds is to gather feedback as the team works on incorporating this feature into JavaFX. Feedback can be reported to the openjfx-dev mailing list._"
