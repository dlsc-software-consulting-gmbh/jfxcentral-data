## Components, Libraries, Tools

* **Dirk Lemmermann** shared multiple messages about FlexGanttFX:
  * "_I finally managed to create a jdeploy installer for FlexGanttFX. You can find it on the updated [FlexGanttFX.com website](https://www.flexganttfx.com/) under 'Downloads/Demo'. The demo shows how this custom JavaFX component manages to draw thousands and thousands of activities below a timeline._"
  * "_A new FlexGanttFX demo app installer is [available online now](https://www.jdeploy.com/~flexganttfxsampler)... These are basically interactive unit tests for various features available by this control. If you are doing planning and scheduling apps, this control is for you._"
  * [This screenshot of a FlexGanttFX demo](https://bsky.app/profile/dlemmermann.bsky.social/post/3mal46a7y522e) shows how it can be used to visualise a project plan imported from MSProject.
* FxmlKit is a modern JavaFX FXML framework with hot reload, zero-configuration loading, and optional dependency injection.
  * [**Lee Wyatt** shared a video on Bluesky](https://bsky.app/profile/leewyatt.bsky.social/post/3maoeqzsizs2h) and [on YouTube](https://www.youtube.com/watch?v=FwZNcqjZ1kY): "_Implementing FXML and CSS hot reloading in FxmlKit. Edit, save, and see the results immediately. No more rebuild-restart loops!_"
  * [**Dirk Lemmermann** announced v1.5](https://bsky.app/profile/dlemmermann.bsky.social/post/3manngcfpf222).
