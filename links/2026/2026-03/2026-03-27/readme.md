* **Frank Delporte** released a new version of Lottie4J, the Java(FX) library to play Lottie animations. "_Version 1.2.0 of [Lottie4J](https://lottie4j.com/index.html) is out, and it's again a big release! The headline feature is support for the `.lottie` container format, but that's just the start. This release also brings marker-based playback, cropping, adaptive rendering, significant performance improvements, and a lot of core model fixes driven by testing more complex real-world animations. Detailed info and a video showing all new features are [explained in this blog post](https://webtechie.be/post/2026-03-20-release-1.2.0-of-lottie4j/)._"
