## Applications

* [**Ilmetallaro** built a 100% offline PDF utility app](https://www.reddit.com/r/JavaFX/comments/1tghhjn/built_a_100_offline_pdf_utility_app_using_java_25/) using Java 25, JavaFX and AtlantaFX (GPLv3): "_LibrePDF is focused on 100% privacy. It makes zero HTTP calls, everything stays locally on your machine, and it doesn't even support logging. I was sick and tired of uploading my personal data to cloud giants (like iLovePDF, Smallpdf, etc.) or relying on sketchy closed-source freeware._" [You can find the code, binaries, and more info here](https://github.com/MontesanoDev/LibrePDF).
