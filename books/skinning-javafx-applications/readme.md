CSS alone won't make JavaFX look modern. Skins will.

**Skinning JavaFX Applications** is a code-first book for developers who want to go beyond basic CSS restyling and master the Control–Skin architecture. It is written for the developer who discovered that no existing control does quite what the project needs, and that some default controls resist restyling from CSS alone.

The first half of the book skins the controls JavaFX already ships. The second half designs original controls for components the platform doesn't provide. 

### What you'll learn

- The Control–Skin architecture: how a skin talks to its control through listeners and bindings, and how layout and CSS fit in
- Runtime theme switching (light / dark) without rebuilding the UI or reediting CSS files by hand
- Fluent materials: Mica, Acrylic and Reveal dissected, plus your own backdrop-blur mechanism
- Professional custom stages and window chrome instead of the OS title bar
- Micro-interactions and animation libraries for polished skins
- Virtualization details
- Building original controls from the ground up

### Contents (10 chapters)

1. The Basic Skeleton — architecture behind controls and skins
2. Updating Properties — ChangeListeners and bindings between skin and control
3. Bounds (optional) — the three kinds of layout bounds
4. Regions and Layouts (optional) — layoutChildren(), clipping and related methods
5. Styling from CSS (essential) — dense chapter on customizing controls with your own CSS rules
6. Switching Modes — light and dark mode without rebuilding the interface
7. Virtualization (optional) — ListView, TableView and TreeView
8. Microinteractions (optional) — small animation library with standard and premium effects
9. Fluent (mandatory) — Mica, Acrylic, Reveal and custom backdrop blur
10. Custom Stages — professional window chrome from scratch

### Who this book is for

You should be comfortable building a JavaFX application: laying out scenes, wiring up FXML or plain Java, and applying basic CSS. The book picks up where the reference documentation stops.
