## Einführung in JavaFX/OpenJFX

Das JavaFX-Framework hat sich seit Version 2 zu einer leistungsfähigen und modernen Technologie
entwickelt, um grafische Benutzeroberflächen (GUIs) im Java-Umfeld zu erstellen. Dieses Buch
richtet sich an Entwickler, die JavaFX von Grund auf erlernen möchten — auch ohne vertiefte
Java-Vorkenntnisse.

### Inhalte

- Widgets und Komponenten des JavaFX-APIs
- GUI-Erstellung direkt aus Java heraus
- FXML-basierter Ansatz für die UI-Definition
- Verwendung des visuellen Designer-Tools **Scene Builder**
- Integration von Swing-Komponenten in JavaFX
- CSS-Styling für JavaFX-Anwendungen

### Für wen ist dieses Buch?

Das Buch eignet sich sowohl für Einsteiger ohne Java-Kenntnisse als auch für erfahrene
Entwickler, die von Swing oder anderen GUI-Frameworks zu JavaFX wechseln möchten.

*Diese zweite, aktualisierte Auflage erschien im März 2022 bei Springer Vieweg.*
