## The Definitive Guide to Modern Java Clients with JavaFX (3rd Edition)

This third and most up-to-date edition of the definitive JavaFX reference has been updated to cover
the latest features in **JavaFX 21 and 23**, including:

- New APIs: `Map`, `FlatMap`, and `OrElse` fluent bindings for `ObservableValue`
- The new **Subscription API**
- Bug fixes and improvements throughout Java

### What You Will Learn

- Create modern client applications in Java using the latest JavaFX 21 and 23
- Build enterprise clients that integrate with existing cloud services
- Use advanced visualization and 3D features
- Deploy on desktop, mobile, and embedded devices

### Who This Book Is For

Professional Java developers who want to master the latest client Java development techniques
for cross-platform applications including desktop, mobile, and embedded devices in the Cloud age.

Written by JavaFX insiders **Stephen Chin**, **Johan Vos**, and **James Weaver** — all Java Champions
and key contributors to the JavaFX ecosystem.
