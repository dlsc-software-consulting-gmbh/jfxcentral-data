## Java in Two Semesters: Featuring JavaFX

This easy-to-follow textbook teaches Java programming from first principles, using **JavaFX
throughout for constructing event-driven graphical interfaces**. Structured as two one-semester
modules, it takes students from complete beginner to confident Java developer.

### What You'll Learn

**Semester One — Fundamentals:**
- Variables, control structures, methods and arrays
- Object-oriented concepts: classes, objects, inheritance, and polymorphism

**Semester Two — Advanced Topics:**
- JavaFX event-driven GUI programming
- Lambda expressions and the Stream API
- Interfaces, generics, and collection classes
- Exception handling, file I/O, multi-threading
- Socket programming and remote database access

### Features

- Each chapter maps to one week of a 12-week semester
- Self-test questions and programming exercises at the end of each chapter
- Two extended worked case studies
- Supplementary resources available at the Springer website

The fourth edition has been fully updated to cover Java 8 features including JavaFX, lambda
expressions, and the Stream API. Ideal for undergraduate modules in software development or
programming with no prior programming knowledge required.
