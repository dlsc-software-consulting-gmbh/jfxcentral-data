## CustomStage

CustomStage is a JavaFX library for creating fully customized, undecorated application windows. It removes the operating system's native window chrome and replaces it with a custom title bar and border drawn entirely in JavaFX, giving developers complete visual control over the window appearance.

The library provides the standard window behaviors (move, resize, minimize, maximize, close) implemented in pure JavaFX, including snap-to-screen-edge functionality. It is compatible with Windows, macOS, and Linux.

CustomStage is ideal for applications that require a distinctive branded look, flat design interfaces, or any scenario where the native window chrome is visually inconsistent with the application's design language.
