## JavaFXSmartGraph

JavaFXSmartGraph is a generic graph visualization library for JavaFX. It lets you display any graph or network structure interactively, with nodes that can be dragged, zoomed, and styled using CSS. The layout algorithm automatically positions nodes using force-directed or circular strategies.

The library is generic and model-agnostic — you provide your own graph model (or use the built-in simple graph implementation) and JavaFXSmartGraph renders it as an interactive visualization. Labels, tooltips, and custom shapes are supported for both vertices and edges.

JavaFXSmartGraph is particularly useful for educational applications, network topology viewers, dependency graph explorers, and any tool that needs to display relational data visually.
