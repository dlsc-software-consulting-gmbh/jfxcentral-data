## CssFX

CssFX is a developer-productivity library for JavaFX that enables live CSS reloading without restarting the application. When you save a CSS file that is applied to your JavaFX scene, CssFX automatically detects the change and reapplies the stylesheet in real time, instantly reflecting the visual change on screen.

Starting CssFX requires just one line of code and has no impact on production builds when not activated. It watches all stylesheets associated with scenes or windows and handles both file-system and classpath resources.

CssFX dramatically speeds up UI styling workflows, particularly for complex applications with many custom CSS rules, allowing rapid iteration on look-and-feel without the compile/restart cycle.
