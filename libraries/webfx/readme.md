## WebFX

WebFX is an innovative JavaFX application transpiler that allows developers to write applications entirely in JavaFX and then compile them to pure JavaScript that runs in any web browser. It bridges the gap between rich desktop JavaFX development and web deployment without requiring any plugin.

The transpiler works by replacing the JavaFX runtime with a custom implementation backed by the HTML5 Canvas and DOM APIs. The resulting JavaScript application runs natively in browsers with performance comparable to hand-written web apps.

WebFX opens the possibility of writing a single codebase in Java/JavaFX that can be deployed as a desktop application, a web application, and a mobile application, dramatically reducing the cost of cross-platform development.
