## JCSG

JCSG is a Java implementation of Constructive Solid Geometry (CSG) based on Binary Space Partitioning (BSP) trees. It allows developers to create complex 3D solid models by combining primitive shapes using boolean operations: union, difference, and intersection.

The library includes a rich set of primitive solids (cube, sphere, cylinder, cone, etc.) and can export models to STL format for 3D printing. It integrates with JavaFX 3D to render and display the constructed geometry in an interactive 3D scene.

JCSG is widely used in creative coding, CAD-adjacent applications, and educational 3D modeling tools in the JavaFX ecosystem, particularly in conjunction with VRL-Studio and other scientific visualization projects.
