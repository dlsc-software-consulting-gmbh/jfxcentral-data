## FX-BorderlessScene

FX-BorderlessScene is a JavaFX library that provides an undecorated (borderless) scene with fully implemented window management behaviors: drag to move, resize from all edges and corners, minimize, maximize, restore, and close. It also supports Windows Aero Snap so the window can be snapped to screen edges.

The library wraps any existing JavaFX scene, making it easy to remove the native window chrome and replace it with a completely custom design. It uses native Windows APIs via JNA to properly implement taskbar integration and snap functionality on Windows.

FX-BorderlessScene is a lightweight and practical solution for creating applications with custom window decorations that still behave correctly as first-class desktop windows.
