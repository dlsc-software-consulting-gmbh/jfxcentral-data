## DockFX

DockFX is a fully featured docking framework for JavaFX that brings Eclipse-style or IntelliJ-style docking behavior to Java desktop applications. Dock nodes can be dragged, dropped, split, tabbed, floated as independent windows, and snapped into predefined docking zones.

The library provides a `DockPane` container that manages the layout of dockable nodes, and `DockNode` wrappers that add the docking chrome (title bar, drag handles, close/float buttons) to any content node.

DockFX is a good foundation for building complex IDE-like or dashboard-style applications where users need to arrange and rearrange multiple panels according to their workflow.
