## TrayNotification

TrayNotification is a lightweight JavaFX library for displaying attractive tray-style notification popups on the desktop. Notifications slide in from a corner of the screen and can contain a title, message, and optional icon, giving users non-intrusive status updates.

The library supports multiple built-in notification types (info, warning, error, success, custom) and allows developers to control duration, position, and animation style. Notifications can be stacked when multiple appear at the same time.

Being dependency-free and easy to integrate, TrayNotification is a popular choice for adding polished notification UX to any JavaFX desktop application.
