## RXControls

RXControls is a JavaFX custom component library that provides a rich collection of additional controls to complement the standard JavaFX SDK. It includes components such as password strength indicators, smooth progress bars, animated buttons, SVG-based icons, and various other decorative and functional UI elements.

The controls are designed with modern aesthetics in mind and provide CSS stylesheets for quick integration. Many components include built-in animation support and configurable properties for fine-tuning their appearance and behavior.

RXControls is a useful complement to other JavaFX UI libraries for developers who want to add distinctive, polished components to their desktop applications.
