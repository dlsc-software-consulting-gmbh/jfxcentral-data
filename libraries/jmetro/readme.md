# JMetro

JMetro is a JavaFX theme inspired by Microsoft's [Fluent Design System](https://fluent2.microsoft.design/). Rather than mimicking the native Windows look, it adapts Fluent Design principles to fit the JavaFX SDK. It is composed of a set of controls, stylesheets, and skins.
