## JFXtras

JFXtras is a broad supporting library for JavaFX that provides helper classes, extended layouts, additional controls, and other useful widgets that are missing from the core JavaFX SDK. It includes date/time pickers, agenda and calendar views, window controls, and various layout panes.

The controls are designed with usability in mind and follow the same conventions as standard JavaFX controls. JFXtras also includes mathematical and CSS helper utilities that simplify common UI programming tasks.

The project is modular, allowing developers to include only the modules they need without pulling in the entire library. It complements other UI libraries like ControlsFX to provide a comprehensive set of JavaFX components.
