## mvvmFX

mvvmFX is an application framework for implementing the Model-View-ViewModel (MVVM) architectural pattern with JavaFX. It provides a structured way to separate UI logic (ViewModel) from presentation (View/FXML) and domain model, resulting in testable and maintainable application code.

The framework handles the wiring between FXML views and ViewModel classes automatically, supports scoped dependency injection, and provides notification and command abstractions that fit naturally into the MVVM model. It also integrates with CDI and Spring for more complex DI scenarios.

mvvmFX is a good fit for enterprise JavaFX applications where clear separation of concerns and testability are priorities.
