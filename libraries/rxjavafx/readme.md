## RxJavaFX

RxJavaFX provides bidirectional bindings between RxJava and JavaFX, allowing developers to bridge the reactive world of RxJava with the property/event model of JavaFX. UI events can be converted to RxJava Observables, and Observables can be bound to JavaFX properties and controls.

This integration makes it straightforward to apply reactive programming patterns — such as filtering, transforming, combining, and throttling event streams — to JavaFX applications. Complex asynchronous UI interactions that would otherwise require tangled callback chains become simple pipelines.

RxJavaFX is part of the official ReactiveX organisation and supports both RxJava 2 and RxJava 3, making it easy to integrate with the broader reactive Java ecosystem.
