## cljfx

cljfx is a declarative, functional and extensible wrapper of JavaFX for Clojure, inspired by React and the re-frame pattern. Instead of manipulating a mutable scene graph imperatively, developers describe the UI as pure data structures and let cljfx efficiently compute and apply the differences.

The library maps Clojure maps to JavaFX component types, supports lifecycle hooks, and integrates smoothly with the re-frame-style event-driven state management. It allows developers to compose complex UIs from small, pure, testable functions.

cljfx is the go-to solution for Clojure developers who want to build rich desktop applications with JavaFX while staying within a functional, immutable programming model.
