## VWorkflows

VWorkflows is a flow visualization library for JavaFX designed for building node-based visual programming environments. It lets you create interactive graphs where nodes can be connected via typed connections (ports), enabling the construction of data-flow or control-flow diagrams.

Connections are drawn as smooth Bezier curves and support validation rules that determine which ports can be connected. Nodes can be freely dragged, and the entire workflow can be serialized and deserialized for persistence.

VWorkflows is used in VRL-Studio, a scientific visual programming environment, and is a great foundation for building visual scripting tools, shader editors, data pipeline builders, or any node-graph application.
