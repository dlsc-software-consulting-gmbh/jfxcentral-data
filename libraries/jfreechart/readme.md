## JFreeChart

JFreeChart is a mature, feature-rich 2D chart library for Java that supports JavaFX, Swing, and server-side rendering. It offers over 20 chart types including bar, line, pie, scatter, area, time series, candlestick, Gantt, and many more, making it one of the most comprehensive charting solutions in the Java ecosystem.

Charts are highly customizable — every visual aspect from colors and fonts to axis labels and legends can be configured programmatically. JFreeChart also supports interactive charts with zoom, tooltips, and mouse event handling when used in a graphical environment.

With decades of development history and widespread adoption, JFreeChart is a battle-tested choice for any application requiring rich data visualization.
