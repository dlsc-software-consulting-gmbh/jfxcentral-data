## graph-editor

graph-editor is a JavaFX library for creating and editing graph-like diagrams with nodes and connections. It provides a model-driven editing surface where nodes can be freely positioned, connected via typed connectors, and styled using CSS.

The library is built on Eclipse EMF for its underlying graph model, providing a structured, persisted representation of the diagram. It supports undo/redo, multi-selection, connector validation, and various layout helpers out of the box.

graph-editor is particularly well suited for building visual workflow editors, data pipeline designers, class diagram tools, or any application where users need to construct and manipulate node-based diagrams.
