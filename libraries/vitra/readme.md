# Vitra

A JavaFX UI library of rich, ready-to-use controls that can be customized entirely from CSS.

Vitra grew out of the code of the most requested controls in the author's own business applications, extracted and turned into a reusable library.

## Goals

- Rich controls that are 100% customizable from CSS
- As few third-party dependencies as possible

## Controls

- Calendar with a modern skin
- File explorer window for choosing a file or a folder
- Notification cards
- Glass panels for glassmorphism-style interfaces
- Gantt chart
- Custom window chrome
- And more

Controls follow the standard JavaFX Control/Skin pattern and expose their visual properties through CSS.
