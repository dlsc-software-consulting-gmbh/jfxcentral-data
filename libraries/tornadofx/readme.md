## TornadoFX

TornadoFX is a lightweight JavaFX framework designed specifically for Kotlin developers. It provides type-safe builders, dependency injection, and a powerful MVC/MVP architecture that lets you write JavaFX applications with much less boilerplate than traditional approaches.

The framework includes a concise type-safe DSL for building UI layouts, view models with automatic property binding, RESTful client support, and a built-in IoC container. It embraces Kotlin idioms like lambdas, extension functions, and coroutines to make UI development feel natural.

Although the repository is now archived, TornadoFX remains widely used and is an excellent choice for teams building desktop applications with Kotlin and JavaFX.
