autumo UI FX is a rapid JavaFX development framework, now open source under the Apache License 2.0. 
It provides the application shell, including lifecycle management, installation, internationalization (PO/gettext), 
user settings and recent files, allowing developers to focus primarily on the code that makes their application unique.

## Features

- Application shell with lifecycle management and a classic MVC structure.
- HTML views and FXML-based user interfaces.
- Configurable multi-step application installer.
- Internationalization with runtime language switching.
- Consistent application theming with customizable CSS.
- Standard dialogs for information, warnings, errors and other common tasks.
- Application configuration and OS-specific data directory handling for macOS, Windows and Linux.
- Logging with SLF4J and Log4j2 on all supported operating systems.
- Native application packaging for macOS, Windows and Linux.
- Developer documentation and a complete demo application.
- ...and much more to simplify JavaFX application development.
