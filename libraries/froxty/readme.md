## FroXty

FroXty is a JavaFX library that reproduces the iOS-style frosted glass translucent background effect for JavaFX nodes. When applied to a pane or control, the background shows a blurred, tinted version of whatever is behind it, creating the distinctive glass-like aesthetic popularized by iOS and macOS.

The effect is implemented using snapshot-based blur rendering and updates dynamically as the background content changes. The blur radius, tint color, and opacity are all configurable.

FroXty is a visual enhancement library ideal for applications that want to adopt a modern, layered design language with depth and translucency as core visual elements.
