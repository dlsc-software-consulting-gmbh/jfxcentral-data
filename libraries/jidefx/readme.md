## JideFX

JideFX is the open-source common layer of the JIDE Software JavaFX library, providing a collection of extensions, helper utilities, and enhanced controls for the JavaFX platform. JIDE Software has a long history of producing high-quality Java GUI components, and JideFX brings some of that experience to JavaFX.

The library includes utility classes for working with properties, converters, field validators, formatted text fields, and common UI patterns. It also provides field-level validators, formatted input fields, and various rendering helpers.

JideFX is particularly useful for business application developers who need robust, production-ready utility classes that go beyond what the standard JavaFX SDK provides.
