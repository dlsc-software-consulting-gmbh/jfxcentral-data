## AnchorFX

AnchorFX is a docking framework for JavaFX that enables the creation of applications with flexible, rearrangeable panel layouts. Dock stations can be split horizontally or vertically, and individual dock nodes can be moved between stations or detached into floating windows.

The framework provides an intuitive drag-and-drop interaction model with visual drop zones that appear when the user drags a panel. Tabbed docking is also supported, allowing multiple panels to share the same screen area and be switched via tabs.

AnchorFX is a solid choice for building workbench-style or IDE-like applications where users need full control over the window layout.
