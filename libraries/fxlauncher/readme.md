## FXLauncher

FXLauncher is an auto-updating launcher for JavaFX applications. It allows you to deploy a small launcher executable to end users, while the actual application and its dependencies are hosted on a web server and downloaded or updated automatically on startup.

The launcher computes a manifest of all required artifacts and only downloads files that have changed since the last run, making updates fast and bandwidth-efficient. It supports custom splash screens and progress indication during the update process.

FXLauncher simplifies the challenge of distributing and maintaining JavaFX desktop applications, bridging the gap between traditional desktop deployment and the convenience of web application delivery.
