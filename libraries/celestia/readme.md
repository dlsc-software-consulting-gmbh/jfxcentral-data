# Celestia

A JavaFX library of micro-interactions: small animated details that add feedback and polish to user interfaces.

Celestia comes in two tiers:

- **Simple** micro-interactions for everyday feedback on controls and UI states
- **Premium** micro-interactions for richer, more elaborate effects

It was created after the book *Skinning JavaFX Applications* and the Vitra control library, and it is meant to add polish to JavaFX user interfaces.
