# SCell

SCell integrates powerful spreadsheet capabilities into Java and JavaFX applications.

## Features

- 150+ Excel formulas supported
- JavaFX 8–21 compatible; single codebase across all versions
- JavaFX view separated from business logic via MVVM framework
- Regular updates with new capabilities and performance improvements

## Fields of Application

SCell suits any scenario requiring data collection, sorting, analysis, or reporting — particularly in finance, engineering, and research. Common use cases:

- Integration with existing enterprise/business (Java-based) applications
- Financial analysis, modeling, and reporting
- Scientific and technical calculations
- Conversion of complex Excel files (e.g., vacation systems, cost calculators)

See the [developer manual](https://scomponents.github.io/scell-public-docs/index.html) for detailed documentation.
