## ScalaFX

ScalaFX is a DSL (Domain-Specific Language) for creating JavaFX-based user interfaces in Scala. It wraps the JavaFX API with idiomatic Scala constructs, making it possible to write concise, type-safe UI code that leverages Scala's powerful language features such as traits, implicit conversions, and higher-order functions.

The library provides wrappers for virtually all JavaFX controls and layout managers, as well as Scala-friendly bindings for JavaFX properties and observable collections. Scene builder-generated FXML can also be loaded and used alongside ScalaFX code.

ScalaFX is actively maintained and supports the latest Scala 3 and JavaFX versions, making it the definitive solution for Scala developers building desktop applications.
