A lightweight MVVM platform for building tab-based JavaFX applications. Consists of a core shell plus ready-made components that significantly reduce development time.

## Features

- Abstract classes to simplify component development
- Dynamically configurable menu with component history preservation
- Inline dialogs with shell and tab scope
- 7 themes (4 dark, 3 light) with CSS styling

## Ready-Made Components

Terminal · Text Viewer/Editor · Dialogs
