## Advanced Bindings

Advanced Bindings is a collection of helper classes and custom binding implementations for JavaFX that extend the built-in `Bindings` utility with commonly needed but missing operations. It provides mathematical bindings (power, log, trigonometry, rounding), string bindings, collection bindings, and various conditional bindings.

The library also includes `MappedList` and `FilteredList` wrappers that support property-based filtering and mapping, and utilities for creating bindings that select nested properties from observable object graphs.

Advanced Bindings is a small, focused library that fills practical gaps in the JavaFX bindings API, reducing the need for custom low-level binding code in day-to-day application development.
