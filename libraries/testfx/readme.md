## TestFX

TestFX is a simple and clean testing framework for JavaFX applications. It provides an expressive API for writing UI tests that can simulate user interactions such as clicking, typing, dragging, and scrolling, and then assert the expected state of the scene graph.

The framework integrates with popular testing frameworks like JUnit 4, JUnit 5, and Spock, and supports both headless (Monocle) and headed test execution. Its fluent API makes test code readable and maintainable.

TestFX is widely used in the JavaFX community to write reliable automated UI tests, and it powers the test suite of many open-source JavaFX libraries including ControlsFX and CalendarFX.
