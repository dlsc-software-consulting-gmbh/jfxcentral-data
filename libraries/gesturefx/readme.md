## GestureFX

GestureFX is a lightweight JavaFX pane that adds pinch-to-zoom and pan gesture support to any content node. Wrap any JavaFX node in a `GesturePane` and users can zoom with scroll wheel or trackpad pinch gestures and pan by clicking and dragging, with smooth animated transitions.

The pane exposes methods for programmatic zoom and pan, supports configurable zoom limits, and fires change events so the application can react to viewport transformations. It works with both touch screens and traditional mouse/trackpad input.

GestureFX is ideal for map views, diagram editors, image viewers, and any JavaFX application where users need to explore content at different zoom levels.
