## Animated

Animated is a modern animation library for JavaFX that brings Flutter-style implicit animations to Java. Rather than manually defining timelines and key values, you wrap a node with `Animated` and declare which properties should animate — changes to those properties are automatically interpolated with smooth transitions.

The library supports a wide range of animatable properties including opacity, scale, rotation, translation, color, and layout. Custom interpolators and easing functions can be applied per-property, and animations can be chained or composed.

Animated dramatically reduces the amount of boilerplate needed to add polished motion to a JavaFX UI, making it easy to create applications that feel fluid and responsive.
