## VFX

VFX is a JavaFX library that provides a collection of additional controls and UI utilities beyond what the standard SDK offers. It includes various interactive components, layout helpers, and styling utilities that simplify the development of feature-rich JavaFX applications.

The library focuses on practical components that are commonly needed in desktop applications but absent from the standard JavaFX control set. Each component is designed to be easily customizable via CSS and programmatic properties.

VFX is a useful addition to the JavaFX developer's toolkit when building applications that require components not found in mainstream libraries like ControlsFX or JFXtras.
