## TerminalFX

TerminalFX is a terminal emulator control for JavaFX that lets you embed a fully functional terminal window inside your application. It uses a WebView-based approach backed by the hterm JavaScript terminal emulator, providing full VT100/xterm compatibility.

The control connects to a real shell process (bash, zsh, PowerShell, etc.) and forwards input and output between the UI and the process. It supports ANSI colors, cursor movement, window resizing, and configurable fonts and color themes.

TerminalFX is ideal for developer tools, IDEs, server management applications, or any JavaFX application that needs to provide direct shell access to the user.
