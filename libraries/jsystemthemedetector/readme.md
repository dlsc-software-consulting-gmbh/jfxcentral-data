## jSystemThemeDetector

jSystemThemeDetector is a Java library that detects whether the host operating system is using a dark or light UI theme. It supports Windows 10/11, macOS, and major Linux desktop environments (GNOME, KDE, etc.), providing a unified API across all platforms.

The library can also listen for theme changes in real time, allowing your JavaFX application to switch its own theme dynamically when the user changes the system preference — a feature users increasingly expect from modern applications.

jSystemThemeDetector integrates naturally with JavaFX applications and popular theme libraries like AtlantaFX or JMetro, enabling fully automatic dark/light mode support with minimal effort.
