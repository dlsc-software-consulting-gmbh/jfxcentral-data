A JavaFX library for generating a wide variety of interactive 3D charts for desktop applications.

![Orson Charts sample](https://user-images.githubusercontent.com/1835893/150652500-87741095-5148-454f-b8e9-8f836174c068.png)

## Features

- Chart types: pie, bar (regular and stacked), line, area, scatter, surface plots
- 360° rotation and zooming via mouse-enabled viewers (JavaFX and Swing)
- Interactive charts with mouse event support on all chart elements
- Configurable tooltips and flexible data sources
- JSON data import/export
- Regular and logarithmic axis scales with auto-adaptive labeling
- Value and range marker annotations
- Export to PDF, SVG, PNG, and JPG
