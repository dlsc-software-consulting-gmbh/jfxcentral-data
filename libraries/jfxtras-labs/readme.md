## JFXtras Labs

JFXtras Labs is the incubator project for the JFXtras library family. It contains experimental, early-stage, and community-contributed JavaFX controls and utilities that are being evaluated for possible promotion into the main JFXtras library.

The project is a proving ground for new ideas — controls in Labs are functional but may have incomplete APIs, less polished styling, or evolving behavior. Developers who need cutting-edge components or want to contribute new controls to the ecosystem will find Labs a useful resource.

Using JFXtras Labs gives access to a wider variety of components than the stable JFXtras release, at the cost of potentially less API stability between versions.
